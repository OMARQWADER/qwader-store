# QWADER STORE (متجر قويدر الرقمي) 🎮🇯🇴

متجر إلكتروني رقمي متكامل فائق الفخامة والسرعة متخصص في بيع ألعاب PlayStation 5 / PS4، اشتراكات PlayStation Plus، بطاقات PSN الأردنية والسعودية والأمريكية، وبطاقات Steam. يعمل المتجر بنسبة 100% على المتصفح والعميل (Client-Side) باستخدام التخزين المحلي `localStorage` دون الحاجة لخادم أو واجهات برمجية خارجية، مع دعم كامل للغتين العربية والإنجليزية وتوافق كامل مع الاتجاهين RTL و LTR، وأسعار بالدينار الأردني (JOD) والدولار الأمريكي (USD).

---

## 🌟 المزايا والمواصفات الرئيسية (Key Features)

### 1. تجربة تسوق رقمية عالمية (World-Class Shopping Experience)
- **واجهة مستخدم نيون وفضائية داكنة (Dark Navy & Neon Violet)** بأعلى معايير التصميم الحديث مع تأثيرات زجاجية ولمسات جمالية مستوحاة من عوالم الألعاب.
- **تصفح سريع وتفاعلي للكتالوج** مع فلترة متقدمة حسب الأقسام (ألعاب، اشتراكات بلس، بطاقات PSN، بطاقات Steam)، والمنصة (PS5, PS4, PC)، والتوافر والمخزون، وترتيب الأسعار والأحدث.
- **تفاصيل المنتج المتقدمة**: معرض صور، ميزات رئيسية، تنبيهات المخزون الحرج، تقييمات العملاء وإمكانية كتابة مراجعات جديدة وحفظها.
- **مقارنة المنتجات (Compare View)**: مقارنة حتى 4 منتجات جنباً إلى جنب في جدول مفصل (النوع، السعر، المنطقة، طريقة التسليم، والتقييم).
- **قائمة الرغبات والمفضلة (Favorites / Wishlist)** مع نقل فوري إلى سلة الشراء.

### 2. عربة الشراء والدفع الأردني المباشر (Cart & Checkout)
- **درج سلة التسوق السلس (Slide-over Cart Drawer)** مع تحكم بالكميات وتطبيق كوبونات الخصم (مثل `QWADER10`, `GAMER20`, `JORDAN5`).
- **شراء بثلاث خطوات سهلة**:
  1. مراجعة السلة وحساب الإجمالي بالدينار الأردني أو الدولار.
  2. معلومات المشتري واختيار وسيلة الدفع (كليك CliQ الأردني الفوري، التحويل البنكي، أو نقداً في عمان).
  3. صفحة إتمام الطلب التفاعلية مع احتفال Confetti، وتوليد كود الطلب، وزر إرسال تفاصيل الفاتورة مباشرة عبر واتساب للمتجر.

### 3. نظام تتبع الطلبات واستلام الأكواد (Order Tracking & Key Delivery)
- خط زمني تفاعلي لتتبع الطلب: (إنشاء الطلب ➔ تأكيد الدفع ➔ قيد التجهيز ➔ تم التسليم).
- إمكانية إرفاق الرقم المرجعي لحوالة كليك لتأكيد فوري.
- صندوق مخصص للأكواد الرقمية وحسابات التفعيل مع زر نسخ بنقرة واحدة عند اكتمال الطلب.

### 4. نظام الصلاحيات المتقدم (RBAC System)
- **👑 مالك المتجر (Owner)**:
  - صلاحيات مطلقة: لوحة تحكم وإحصائيات المبيعات، إدارة المنتجات والمخزون، إدارة الطلبات وتسليم الأكواد، إدارة رتب المستخدمين والمشرفين، مراجعة التقييمات، إعدادات المتجر العامة، وتفعيل/إيقاف وضع الصيانة، وتصدير/استيراد قواعد البيانات (JSON Backup) والتهيئة لمصنع.
- **🛡️ مشرف المبيعات (Staff)**:
  - إدارة المنتجات وتحديث الكميات، معالجة الطلبات وإدخال الأكواد الرقمية، الرد على تذاكر الدعم الفني، وإدارة التقييمات.
- **👤 العميل والزبون (Customer)**:
  - تصفح الكتالوج، الشراء، متابعة الطلبات، كتابة التقييمات، وإرسال تذاكر الدعم.
- **أداة التبديل السريع (Quick Role Switcher)**: شريط عائم في أسفل الشاشة للتبديل الفوري بين أدوار (Owner / Staff / Customer) لتسهيل التجربة والمعاينة دون الحاجة لتسجيل الخروج.

### 5. نظام الدعم الفني والتذاكر المباشرة (Support Tickets & WhatsApp)
- فتح تذاكر جديدة لمشاكل التفعيل وتأكيد الدفع والاستفسارات العامة.
- نظام محادثات حية وتحديث للردود بين العميل والإدارة.
- زر واتساب عائم للتواصل اللحظي.

### 6. وضع الصيانة (Maintenance Mode)
- إمكانية تفعيل وضع الصيانة من إعدادات لوحة التحكم، مما يُظهر شاشة صيانة احترافية للزوار مع الحفاظ على إمكانية وصول المالك للإدارة.

## 💾 هيكل التخزين المحلي (LocalStorage Architecture)
- `qwader_store_data_v1`: يحفظ قائمة المنتجات، الطلبات، المستخدمين، التقييمات، تذاكر الدعم، وإعدادات المتجر.
- `qwader_store_session_v1`: يحفظ بيانات المستخدم المسجل حالياً، لغة العرض، العملة، المفضلة، وسلة الشراء.
